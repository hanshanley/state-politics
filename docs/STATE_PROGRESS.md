## Cycle inclusion and stopping rules

Use publisher-native annual/biennial sessions and verified filing/introduction
evidence, not a session-name substring or a guessed date from a URL. Overlapping
biennia require record-level inclusion; regular and special sessions remain
distinct. Missing dates or native-universe evidence stay explicit rather than
being filled from latest-action dates. State totals below describe their named
accepted packets, not newly computed 2023–2024 analytical denominators.

Reuse the target-cycle portion of wider accepted archives. Do not collect the

## How to use this list

- **Closed scope:** collection/accounting and independent replay accepted for
  the specified cohort, including its explicit negative dispositions.
- **Partial:** useful native evidence or a bounded recovery is accepted, but
  the state's source cohort is not closed.
- **Blocked:** the named gap prevents continuation/closure. Accepted earlier
  work stays accepted; do not repeat it to manufacture a new completion.
- **In progress:** a newly assigned, explicitly bounded task; not completion.
- **Inventory:** retained national data exists; dedicated native closure is
  not established.

Before assigning work, check this row and the existing task/owner. Assign the
**remaining gap**, not "redo the state." Record the exact cohort, task/owner,
accepted evidence and unresolved blocker when changing status. Mocked transport
and collector-readiness tests never count as recovered official documents.
Old SQL `in_progress` entries alone do not prove a live agent or collector.
Unknown request history is not zero; this list grants no HTTP allowance or
permission to restart a campaign. Source packets remain local/Git-ignored;
pushing this tracker is not a backup of their bytes.
