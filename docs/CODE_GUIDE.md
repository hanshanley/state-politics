# Code guide

This guide accompanies every Python file in `src/`, `scripts/`, and `tests/`. It explains what
each file owns, its inputs/outputs, and where it sits in the reproducible pipeline. The
repository audit fails when a Python file is added without an entry here.

## Package and infrastructure

| File | Responsibility |
|---|---|
| `src/state_politics/__init__.py` | Package version and public package metadata. |
| `src/state_politics/provenance.py` | Fetches network resources, blocks SSRF/private addresses, follows checked redirects, releases consumed/error responses before reuse, hashes successful content, and optionally appends logical-retrieval JSONL provenance records; does not itself retain complete redirect/retry/error-body evidence or enforce cross-attempt request budgets. |
| `src/state_politics/compute.py` | Selects the available model execution device and enforces the no-hosted-inference dependency rule. |
| `src/state_politics/storage.py` | Shared native `clonefile` primitive and fresh-file evidence copying. macOS uses independent copy-on-write files and refuses native-clone failures without full-copy fallback; other systems stream complete files using exclusive creation. Never overwrites an existing destination or follows a linked source. |
| `src/state_politics/caucuses.py` | Collects the four explicitly separate legislative-caucus priority sources into `caucus_priorities.parquet`; never labels them party platforms. |
| `scripts/reclaim_generated_storage.py` | Defaults to a manifest-only dry run over completed generated bundles. An explicit, separate previews-only scope reads bound full evidence/download outputs without repeating the bundle batch. APFS reclamation replaces only SHA-identical duplicates with independent native copy-on-write clones, preserving paths/content/metadata and immutable sources; refuses active servers/builders, unsafe paths, races and full-copy fallback, with a per-file journal and measured disk recovery. |
| `tests/test_generated_storage.py` | Verifies clone independence, unchanged source/content/metadata, refusal of mismatches/symlinks/concurrent changes, cleanup after clone failure, safe paths, strict scope selection, active-server/preview-builder refusal, preview content matching and exclusion of unfinished/failed/unknown-schema/linked snapshots. Tests fresh-file portable/native evidence copying, no full-copy fallback and preservation of existing files/links. Executes legacy `clean-derived` only against absolute disposable fixture paths to prove it refuses deletion and preserves retained tables/figures. Verifies broad legacy builds refuse before dependencies, in serial/parallel Make, while explicit opt-in retains the historical commands. |
