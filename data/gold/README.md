# Hand-labelled validation data

`plank_topics_gold.csv` is the only manually labelled analytical dataset in the repository.

## What was labelled

- 50 platform planks
- randomly drawn from the confirmed 2018-present corpus on 2026-07-29
- sampling seed: `20260729`
- one CAP major-topic code per plank, using `conf/topics.yml`
- one annotator

The complete sampled text is embedded in the CSV. This preserves the validation snapshot even
when the source corpus grows or extraction improves.

## Label protocol

1. Read the complete plank.
2. Assign the single CAP topic that best describes its dominant substantive claim.
3. Do not inspect the classifier prediction while assigning the label.
4. Where two topics are defensible, select the dominant one; evaluation also reports top-2.
5. Use only codes in `conf/topics.yml`; never add an ad hoc category.

Generate a deterministic **new** unlabeled template from a current corpus:

```bash
uv run python scripts/sample_gold_planks.py --seed 20260729 --size 50
```

This writes `data/processed/plank_topics_labeling_template.csv`; it never overwrites the
versioned gold set. Re-score the fixed manual labels with:

```bash
uv run python -m state_politics.analysis.validate
```

The label decisions cannot be generated by code. Their source text, schema, seed, taxonomy,
hash, and downstream scoring are audited by `scripts/audit_reproducibility.py`.
